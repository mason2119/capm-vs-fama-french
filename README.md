# CAPM vs Fama-French 三因子：谁更能解释 A 股收益？

> 对 100 只沪深 300 成分股的 84 个月度收益（2018/01–2024/12，共 8,400 个观测）逐只做时间序列回归，
> 从拟合优度、因子显著性与截距项三个维度，比较单因子 CAPM 与三因子模型对 A 股横截面收益的解释力。
>
> **课程结课项目 · 独立完成**

---

## 一、核心结果

| 指标 | CAPM | FF 三因子 | 提升 |
| --- | ---: | ---: | ---: |
| 平均 R² | 0.2370 | **0.3709** | +0.1338（相对 **+56%**） |
| 平均调整 R² | 0.2277 | 0.3473 | +0.1195 |
| R² 中位数 | 0.2062 | 0.3655 | +0.1593 |
| R² 范围 | [0.019, 0.629] | [0.058, 0.705] | — |

- **100 只股票全部改善**，无一例外，最大 ΔR² = 0.4732
- 调整 R² 同样提升，排除「变量增加导致机械性提升」
- AIC 支持三因子的股票占 84%，BIC 占 70%

### 但有一个反直觉的发现

| 指标 | CAPM | FF 三因子 |
| --- | ---: | ---: |
| Alpha 显著 ≠ 0 比例（α=5%） | 10.0% | **16.0%** |
| Alpha 显著 ≠ 0 比例（α=10%） | 18.0% | 26.0% |
| 平均 \|Alpha\|（%/月） | 1.0586% | 1.0868% |

**加入 SMB 与 HML 后，显著 Alpha 的比例不降反升（10% → 16%）。**

机制：三因子 R² 更高 → 残差方差下降 → Alpha 的标准误变小 → t 值变大 → 更多个股的异常收益变得统计显著。
而平均 |Alpha| 几乎没变（1.0586% → 1.0868%）。

**所以结论是**：三因子模型确实更好地解释了收益的共同变动，但**并没有消除 A 股的定价异象**。
「多因子解决一切」是错觉。

## 二、因子暴露

| 因子 | 5% 显著比例 | 10% 显著比例 | 平均 \|t\| | 平均载荷 |
| --- | ---: | ---: | ---: | ---: |
| Mkt-RF（市场） | **97.0%** | 99.0% | 5.8 | 0.885 |
| SMB（规模） | 37.0% | 45.0% | 1.8 | 0.280 |
| HML（价值） | 66.0% | 69.0% | 3.1 | 0.152 |

**注意区分两件事**（这是本报告最容易误读的地方）：

- **HML 载荷 66% 显著** → 说明个股对价值因子有稳定敏感度，HML 是有效的解释变量
- **HML 因子本身的溢价不显著** → 全样本均值 **−0.181%/月（t = −0.30）**，价值组合并没有系统性跑赢成长组合

「暴露显著」≠「溢价显著」。不能因为载荷显著就说「价值风格占优」。

### 因子描述性统计

| 因子 | 均值（%/月） | 标准差（%/月） | t 值 |
| --- | ---: | ---: | ---: |
| Mkt-RF | −0.008 | 5.507 | −0.01 |
| SMB | −0.039 | 3.416 | −0.10 |
| HML | −0.181 | 5.606 | −0.30 |

三个因子在全样本上的均值都不显著。

## 三、数据与方法

### 样本

| 项目 | 说明 |
| --- | --- |
| 股票池 | 沪深 300 成分股中 100 只（数据完整度 ≥78%） |
| 时间区间 | 2018 年 1 月 – 2024 年 12 月（84 个月度） |
| 观测数 | 8,400 个股-月度 |
| 数据来源 | baostock（证券宝），指数代码 sh.000300 |
| 无风险利率 | 1 年期定存基准 1.5% p.a.（0.125%/月） |

### 因子构造

| 因子 | 定义 |
| --- | --- |
| Rm − Rf | 沪深 300 月度收益率 − 无风险利率 |
| SMB | 中证 500 收益率 − 沪深 300 收益率（小盘 − 大盘） |
| HML | 基于 PB 分组：低 PB/高 BM 组合 − 高 PB/低 BM 组合 |

> ⚠️ **方法论说明**：标准 FF 三因子采用 2×3 分组的市值与账面市值比构造 SMB/HML。
> 本项目为课程作业约束下的**简化构造**，会影响载荷的绝对数值，也影响与国际文献的可比性。
> 详见「局限」一节。

### 模型

$$R_i - R_f = \alpha_i + \beta_i(R_m - R_f) + \varepsilon_i$$

$$R_i - R_f = \alpha_i + \beta_i(R_m - R_f) + s_i \cdot SMB + h_i \cdot HML + \varepsilon_i$$

对每只股票分别做 OLS，再横截面汇总 R²、t 值、Alpha。

## 四、8 年四次风格轮动

| 时期 | 关键事件 | 风格表现 |
| --- | --- | --- |
| 2018 | 中美贸易摩擦、金融去杠杆 | 整体下跌，价值抗跌，大盘优于小盘 |
| 2019 | 科创板开板、MSCI 扩容 | 成长股反弹，风格快速切换 |
| 2020 | 疫情 + 全球宽松 | 龙头白马领涨 |
| 2021 | 碳中和、结构性牛市 | 新能源/半导体成长赛道爆发 |
| 2022–2024 | 经济下行、地产调整 | 高股息/价值防御回归，「中特估」 |

这正是单因子模型失效的根源：CAPM 假设只有一种系统性风险，而 A 股 8 年间至少四次风格切换。

## 七、局限

| 局限 | 说明 |
| --- | --- |
| **因子为简化构造** | 用「中证 500 − 沪深 300」代理规模、PB 分组代理价值，非标准 2×3 分组 |
| **样本选择偏差** | 只取沪深 300 且要求完整度 ≥78%，退市/调出成分股的样本被剔除（survivorship bias） |
| **未做稳健性检验** | 未用 Newey-West 调整标准误，未做子区间回归（8 年跨四种风格，全样本平均会掩盖结构差异） |
| **未对照五因子** | 无法判断剩余 Alpha 是否会被 RMW/CMA 吸收 |

---

## 八、如果重做

1. 按标准 FF 方法构造因子（市值中位数 × BM 三档的 2×3 分组），使结果可与国际文献对比
2. 补做子区间回归（2018–2020 / 2021–2024），避免全样本平均掩盖风格切换
3. 加五因子对照，判断「三因子未能解释的 Alpha」是模型不足还是真实异象
